# Oceanus — Human-AI Collectives (example field)

**Status:** drafting practice. No force. Not a council. Not a citizenship registry.  
**Seated on paper:** 2026-09-17  
**Plane:** this repository is the Oceanus *field* pack. It is not [HASEOS-IDAO](https://github.com/noahnemo-rgb/HASEOS-IDAO).

Oceanus is **one ecology** used to show how a HAC actualizes HASEOS in a field. Other ecologies copy the method, not this scenery.

A HAC does not enroll HASEOS members. It does not ratify `constitution/` in this repo. It does not open `citizenship/` as a live roll. It does not require Our New Era (ONE) Church, or any spirituality. All sovereigns in a bound field remain under HASEOS and, when it exists, this field’s own constitution.

HASEOS drafts stay in the HASEOS pile. Oceanus drafts stay here.
