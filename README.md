# Oceanus

> ONE worldwide boundless borderless ocean nation

**Maturity:** `drafting`  ·  **Parent:** [ONE Ecology](https://github.com/noahnemo-rgb/ONE-) → [ONE Universe](https://github.com/noahnemo-rgb/ONE-)  ·  **Governed by:** [HASEOS](https://github.com/noahnemo-rgb/haseos-spiral-swarm)
