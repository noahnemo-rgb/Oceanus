# Oceanus — BRAND/

This folder holds the visual identity for Oceanus.

## What goes here

- `logo-*.{svg,png,jpg}` — primary and alt logos
- `palette.md` — color tokens
- `typography.md` — font choices
- `voice.md` — brand voice

## Inheritance

Oceanus inherits the ONE Universe master palette and extends it with ocean-specific tokens.
